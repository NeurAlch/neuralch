From the words Neural + Alchemy. Code is art, alchemy, fun, creativity, engineering.

## Some Work

- Worked on all size of full-stack projects from startups to enterprise last 15 years
- Create a few internal tools for 3 enterprise Fortune 500 clients (healthcare)
- Created a prototype AI chat with RAG and guardrails for enterprise (healthcare)
- Did a full white-label enterprise sms communication tool used by biggest telecoms in LATAM
- Created a small Python framework on top of Werkzeug
- Worked on a stack for millions of SMS delivered, with ActiveMQ/Java
- Created a full site builder in PHP for a startup
- Worked on a site with millions of users optimizing with Memcache/PHP
- Created a bootloader and toy OS with some friends for fun, ASM/C
- Did a small spreadsheet with ASM/Pascal

### Some Side Projects

- Forge: AI orchestration, agent workspace, local tool control, and learning / reading environment
- Voxel Art Editor: Pixel-art-like creation with voxels, movement, and simulation
- NVIM Custom Plugins: Code highlighting, editor context, and custom developer workflows
- Life Simulations: Small systems for emergence, agents, and interactive simulated worlds
- Polymarket bots: Kept a win rate of 55% on BTC 15m
- Aurion: Personal AI tools with multi-agent chat, early agentic flows, voice, LLMs, and MCP exploration
- Notebook: Workflowy-inspired outlining and note-taking
- Text Tools: Chainable text transformations and complex React interactions
- SEO Tools: SERP correlation, keyword discovery, Chrome extensions, and SEO research utilities
- Grow SEO: Shopify SEO app with paying customers, Node, React
- Tipzza: A site for sharing tips, build in Django, jQuery, MySQL
- OS / Bootloader: Bootloader and operating system experiments in ASM and C
- Build a spreadsheet with Pascal and inline ASM for UNI homework
